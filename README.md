# Tab to Todoist

[![CI](https://github.com/probecat/tab-to-todoist/actions/workflows/ci.yml/badge.svg)](https://github.com/probecat/tab-to-todoist/actions/workflows/ci.yml)

A Firefox add-on that adds the current tab to Todoist as a link task.

[![Get the add-on for Firefox](docs/get-the-addon.svg)](https://addons.mozilla.org/firefox/addon/tab-to-todoist/)

See [Releases](https://github.com/probecat/tab-to-todoist/releases) for additional signed builds.
